# 可分享仓库与独立部署实施计划

使用 executing-plans 按步骤执行并验证。

## 目标与边界

源码保存在仓库目录，默认部署位于同级 `<仓库名>-deploy`。部署目录包含 app、state、tools、cache、tmp。运行时的数据库、凭据、会话、报告和下载均进入部署目录。

公开配置使用 JSON 白名单种子，首次运行生成 SQLite。保留默认研究配置、自定义模板与内置模板隐藏设置。清除机器目录、账号、密钥和研究数据。JSON 便于提交前审查和跨版本迁移。

自动安装入口为 Windows 与 macOS 启动脚本，调用统一 Node 安装程序。缺少 Node.js 24 时下载官方便携版本并验证摘要。安装 Copilot CLI 与 CLIProxyAPI 对应架构，校验发行资产后配置本机服务。

install.prompt 单独提供技术栈、依赖、手工安装与部署步骤、登录及验收要求，安装过程不调用自动安装入口。

## 实施步骤

- [x] 建立统一部署路径、环境变量传递和新数据库种子加载，添加回归测试。
- [x] 导出当前基础设置和模板，排除历史任务、资料、产物及凭据。
- [x] 编写跨平台安装、运行入口及手工安装提示词。
- [x] 迁移本机数据与工具，替换历史路径，保留迁移备份并验证数据完整性。
- [x] 更新公开说明与忽略规则，扫描待发布文件和已知私密值。
- [x] 初始化 Git，核查暂存内容，运行测试与独立部署验收。

## 验证要求

Windows 安装、路径分离、原数据库数量、报告读取、账号连接状态、安装重复执行、空部署种子、macOS 两种架构的资源选择、依赖检查、公开文件审计均需要验证。macOS 原生终端与实际安装效果需在 macOS 实机复核。

## 验证记录

Windows PowerShell 5 安装入口、CMD 重复安装、NODE_ENV=production 安装与独立部署启动均已通过。迁移前后记录数一致，报告及凭据字节哈希一致，续写作用域通过路径与账号校验。公开种子生成的空数据库通过检查。macOS Intel 与 Apple Silicon 发行资产和摘要已核对，实机运行待验证。Git 初始化并暂存经审计的公开文件，供首次提交使用。
